📘 Overview

The Student Grading System is a Python-based console application designed to manage student academic data.
It helps educators register students and courses, input grades, and compute Cumulative GPA (CGPA) using the DBU grading system.
All data is stored in text files, making the system lightweight and easy to run on any computer.

✨ Features

👨‍🎓 Register Students (ID, Name)

📚 Register Courses (Code, Title, Credit Hours)

📝 Record Grades for students

🔢 Automatic Grade Point (GP) calculation

📊 GPA calculation + Transcript generation

💾 File-based persistent storage

🔐 Input validation & error handling

🖥️ Console-based UI with ASCII headers
